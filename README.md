# learn-user-journey-analytics-with-phoebe

Where the numbers happen: the ecommerce in-app journey, measured. A two-track interactive
course by Phoebe Fu - course 2 of the ecommerce & growth analytics series on the
[Learn with Phoebe](https://phoebefu6.github.io/learn-with-phoebe/) hub.

- **Leader track (a1-a6)** - reading mode: the journey map and its five entry doors, search
  vs browse, the PDP as decision room, what honestly kills checkouts (Baymard), and the
  prioritization ritual for journey fixes.
- **Analyst track (b1-b8)** - computing mode: Mango Lane's screen map with real counts,
  entry-point and path analytics, a live journey-flow simulator (toggle four classic fixes
  and watch conversion climb 2.7% to 4.0%, GMV +47%), PDP engagement, the checkout
  micro-funnel, leak diagnosis, and the journey scorecard.

Same store and month as learn-ecommerce-metrics-with-phoebe - every count reconciles.
Static HTML/CSS/JS, no build step.

Built from GA4/Firebase documentation (path exploration, funnel exploration, screen tracking,
landing pages, source scopes, site search), Baymard Institute checkout research, the Spiegel
Research Center review study, and flagged vendor benchmarks.

by Phoebe Fu
